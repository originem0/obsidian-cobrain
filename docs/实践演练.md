# Cobrain 实践演练

适用于 0.6.1。这是操作示例，不是某次真实模型运行的实录；回答措辞会随端点、模型和材料变化。

## 选一篇材料开始

在 Obsidian 中打开一篇 Markdown 文档，例如你保存的因果推断文章。新建副脑会话，顶部材料行应显示这篇文档。

如果文章来自别人，在材料管理中标为外部材料；不知道归属就保持归属未确认。你的库里存在这篇文章，不代表你认可原作者的全部观点。

输入一个具体任务，例如：

```text
解释这篇文章如何区分相关性与因果关系。
先给核心判断，再指出作者用哪项证据支持它。
```

副脑应围绕附加材料完成解释，带上来源，并区分作者判断和自己的补充。普通对话不需要嵌入端点，也不会后台搜索其它笔记。

## 讨论选中的一段

在编辑模式选中你不理解的一段，运行「讨论选中文本」或用右键菜单。这段原文以快照加入会话，替换同篇全文引用。

```text
这里从两个现象共同出现，推到了一个因素导致另一个。
这一步成立需要补哪项证据？
```

这一轮只使用选区与会话上下文。需要看全文时，在材料管理中重新添加全文；切换编辑器里的文档不会自动改变已有会话范围。

## 推敲而不急着认可

继续说出你的判断，也可以明确保留意见：

```text
我理解作者的解释，但还不认可这个因果结论。
请检查它是否排除了共同原因。
```

更多菜单中的「推敲观点」会检查当前讨论的主张。它应注明是谁提出的，指出影响结论的缺口；论证充分时也可以说明在哪些条件下成立。

用户继续追问，不代表认可副脑的答案。发现它把自己的推论写成你的立场，应纠正归属。

## 需要对照材料时再检索

已知另一篇文档时，直接从材料管理添加。需要找其它资料时，先在桌面设置允许索引的目录，启用可选索引并配置嵌入端点。

从更多菜单打开「手动查找其它资料」，限定目录并搜索。结果需要主动选中并添加，搜索本身不会把结果交给模型。允许目录留空表示不索引任何文档。

## 画概念图并审阅关系

在更多菜单选择「生成概念图」。检查图里的关系是否有材料依据：共同出现不应自动变成导致；未解决的连接应标明待验证；原作者的主张和副脑的假设不应变成你已确认的结论。

材料很少时，节点可以少于目标密度。不要为了画满图而补造连接。生成的 Mermaid 仍需检查格式，插件没有独立的语法验证闭环。

## 保存下次能接着想的笔记

在更多菜单选择「整理为笔记」。预览中可修改标题和正文，确认后保存。检查是否留下了判断的理由、会改变结论的限制，以及真正未解决的问题。

尚未认可副脑的推论时，可以把相关句子改为：

```text
原作者认为干预证据可以支持因果判断。
讨论提出共同原因仍需排除，这项解释尚待验证。

> [!question]
> 文章中的干预例子是否排除了共同原因？需要回到实验设计核对。
```

不要让笔记代替你宣布已经想通。未确认存在的笔记目标保持普通文字，生成笔记的来源区由实际会话材料追加。

需要全部原话时，选择「导出完整会话」。它直接保存全部提问与回答，不经过模型蒸馏，也包含尚未在界面展开的早期记录。

## 调整设置与继续会话

设置页所有分区可同时展开并向下滚动。三组提示词分别影响对话、概念图和笔记；推敲观点和长期摘要使用独立策略。旧默认值自动更新，自定义内容保留，恢复默认逐项生效。

从历史按钮继续这段会话。全文材料会重新读取最新内容，选区快照保持原样。手机普通回车换行，点击发送；回答期间仍能起草下一问。

如果提示本轮使用长文节选，只能判断已发送的内容，不能把局部讨论当成全篇总结。来源标注、模型回答与概念图也不等于事实核验。
