# 0.6.2 · 恢复目录审核合规、会话同步保护与模型手填

本版修正让 Cobrain 从社区插件目录搜索中消失的审核问题，同时处理跨设备会话覆盖、模型配置入口与流式请求的几个缺陷。

## 社区目录

社区目录会扫描每个新版本，出现高风险项的插件会从搜索和应用内安装列表移除。0.2.5 的描述含有「Obsidian」一词，插件自 2026-06-30 起不再出现在搜索中；0.3.0 起声明的最低版本低于代码实际使用的 API，输入框自动增高又直接写入了内联样式。三项在本版全部修正：描述改为英文且不含禁用词，最低版本与 API 对齐，输入框高度改用 CSS 变量。README 恢复英文说明。

开发检查改用目录审核同一套规则（eslint-plugin-obsidianmd）。规则错误或新增警告都会让 CI 与发版失败；有意保留的 8 条警告及原因写在 `eslint.config.mjs` 中。

## 会话同步

- 另一台设备更新了同一会话，而本地也有未保存的改动时，不再覆盖对方的内容。本地内容另存为「· 同步副本」，两边记录都保留；本地没有改动时直接接续外部更新。
- 每次保存先写一份独立快照。两台设备同时写入时，重启后可从快照找回被覆盖的一方，保存为「· 恢复副本」。
- 打开历史会话列表时重新读取目录，可以看到其它设备新建的会话；目录按条目合并，不再整体覆盖。
- 同一会话在两台设备交替编辑时可能产生副本，多余的一份需要手动删除。数据不会因此丢失。

## 设置

- 模型名称可以直接填写，检测只是辅助，端点不提供 `/models` 也能使用。嵌入模型在离开输入框时才保存，不会每输入一个字就清空索引；移动端仍为只读。
- 密钥说明改为如实描述：API Key 以明文保存在库内插件数据中，同步插件目录时也会同步。
- 设置页的静态样式移入 `styles.css`，便于主题覆盖。

## 请求与数据校验

- 只有端点明确表示不支持 stream 参数时才降级为非流式重试；认证、限流与服务错误不再重复发送请求。
- 收到 `[DONE]` 即视为回答完成并释放连接。代理迟迟不关连接或随后断开，不会再让完整回答变成失败。
- 会话文件、模型列表、嵌入响应与索引分片的解析改为逐层校验；同步冲突留下的残缺索引分片会被跳过，不再挂到无效路径上。

## 升级

安装包 `cobrain-0.6.2.zip` 包含 `main.js`、`manifest.json`、`styles.css`，三个文件也单独提供。替换 `.obsidian/plugins/cobrain/` 中的这三个文件，保留 `data.json`、`sessions/` 与 `index/`。桌面重新加载插件，移动端同步后重启 Obsidian。

最低 Obsidian 版本由 1.5.7 调整为 1.7.2，与代码使用的 API 一致。仍在 1.7.2 以前版本的用户会停留在 0.6.1。没有新增运行依赖。

## 验证

本地验证通过 23 个套件共 170 项测试、TypeScript 检查与生产构建、目录审核规则检查（0 错误，8 条已记录的保留警告）与发布元数据检查，以及 10 项浏览器交互检查、3 项设置检查、5 种聊天布局和 4 种设置布局。

浏览器验证使用 Obsidian 宿主适配层，不替代真实宿主、手机和实际同步服务的验收。会话同步保护在模拟文件系统上验证了覆盖、并发写入与中断场景，尚未在真实同步服务上逐一复现。
