# 0.6.0 · 文档对话与会话重构

> 历史版本记录，验收数字与行为描述对应 0.6.0。当前版本为 0.6.2，参见[最新改动说明](0.6.2-change-notes.md)与[使用手册](使用手册.md)。

默认流程从自动全库检索改为会话固定的文档讨论。文本模型是唯一必需配置。

## 行为变化

- 会话独立文件保存，取消三个草稿槽位及八十条原文截断；桌面多面板，移动端单界面切换历史。
- 文档范围固定在会话中，读取最新内容。选文是持久原文快照，默认替换同篇全文引用。
- 对话不自动检索，也不调用查询改写。手动检索可以进一步限定目录，结果需选择添加。
- 可选索引默认关闭；允许目录留空不索引。旧索引在运行时也必须通过当前允许与排除规则。
- 上下文改为估算容量管理，较早消息先完整纳入连续摘要。摘要失败则停止本轮，原文保留。
- 读取材料时注明作者、出处与归属。生成笔记标明 AI 整理，避免反复检索后被当作用户原有立场。
- 配图客户端、端点和设置、提示词编辑、附件生成与管理、保存中的配图选项移除；已有文件保留。
- 推敲、概念图、保存和完整导出进入更多菜单。摘要笔记保存前可编辑正文。
- 手机回车换行，处理中文组合输入；等待时可继续起草，完成不抢焦点、滚动位置或键盘。

## 迁移

旧草稿只迁移一次，源草稿保留为备份；删除迁移后的会话不会再次恢复旧草稿。旧图像引用保留到会话历史。

原样默认提示词更新到新的归属规则，自定义内容保留。索引不会因升级自动恢复为全库模式，原有索引文件也不会绕过新范围。

## 验证方式

`npm test -- --runInBand` 覆盖会话恢复、写入失败、摘要连续性、停止与取消、范围变化和索引过滤等逻辑。

`npm run build` 执行完整 TypeScript 检查并生成插件文件。

`npm run test:ui` 使用本机无界面浏览器运行实际界面与业务模块，检查会话切换、部分回答保存、未发送草稿、长历史分页、完整导出、保存快照、中文输入、滚动与焦点，并检查 320/390 像素窄屏、键盘压缩视口、桌面及深色主题。

浏览器的 Obsidian 宿主是适配层，模型和文件使用测试数据。它不能证明手机系统键盘与实际 Obsidian 宿主的全部行为，仍需要真机使用反馈。

本次本地验收通过 23 组共 145 项测试、TypeScript 与生产构建，以及 10 项浏览器交互检查和 5 种布局检查。安装包包含 main.js、manifest.json、styles.css，版本为 0.6.0。
